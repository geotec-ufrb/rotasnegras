# 🌍 Rotas Negras

Projeto desenvolvido pelo **GEOTEC/UFRB** com foco na valorização, visibilidade e mapeamento de territórios, trajetórias e comunidades negras, utilizando ferramentas de **geotecnologia e web mapping**.

## ✊🏿 Sobre o projeto

O **Rotas Negras** tem como objetivo construir mapas interativos que evidenciem:
- Comunidades quilombolas
- Rotas históricas e culturais
- Territórios de resistência negra

A proposta é unir **tecnologia, ciência e justiça social**, promovendo acesso à informação geográfica de forma crítica e inclusiva.

## 🧭 Funcionalidades

- 📍 Mapeamento georreferenciado de pontos de interesse
- 🗺️ Visualização em mapa interativo
- 📊 Integração com dados territoriais
- 🌐 Aplicação web acessível

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript  
- Bibliotecas de mapas (ex: Leaflet / outras, conforme uso)
- Banco de dados geográfico (se aplicável)
